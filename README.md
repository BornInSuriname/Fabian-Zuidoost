# Fabian Zuidoost – andere campagnewebsiteversie (2026)

> **Historisch project.** Deze repository bevat een andere versie van de campagnewebsite van Fabian Vroom uit 2026. De informatie over kandidaatstelling, stemmen en verkiezingen kan verouderd zijn.

## Waarom deze repository bewaard blijft

Deze broncode verschilt op onderdelen van de andere campagnerepository. De projectgeschiedenis blijft voorlopig beschikbaar, zodat er niets verloren gaat en beide versies kunnen worden vergeleken.

- **Techniek:** HTML en Tailwind CSS (via CDN).
- **Hoofdbestand:** `index.html`
- **Overige bestanden:** map `assets/`
- **Andere versie van de campagnewebsite:** https://github.com/BornInSuriname/Fabian-Vroom-ZuidOost
- **Huidig persoonlijk portfolio:** https://borninsuriname.github.io/

## Gebruik

Open `index.html` om de bron lokaal te bekijken. Houd er rekening mee dat sommige stijlen, lettertypen en iconen internettoegang nodig hebben.

**Let op:** De oorspronkelijke campagnewebsite wordt hier als archief bewaard. Deze repository is niet bedoeld als actuele gemeentelijke informatiebron.
